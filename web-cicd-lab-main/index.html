Web CI/CD Lab — Jenkins + Docker + GitHub Webhook

This static page is served from an nginx Docker container. It's deployed by a Jenkins Freestyle job that's triggered automatically by a GitHub webhook every time this repository is pushed to.

To prove the pipeline works end to end: edit this page (e.g. bump the badge above to v2), commit, push — and watch Jenkins rebuild and redeploy the container automatically without you touching the terminal.
